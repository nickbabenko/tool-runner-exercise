# Tool Runner

Python 3.9+, standard library only. Nothing to install.

**Part 1:** write `run_tools` in `tool_runner.py`. The task is described in the comments at the top of that file. Check your work with:

```
python3 check.py
```

**Part 2:** review the `run_agent` PR in `agent.py`. Run it with:

```
python3 shop.py
```

`model.py` (a mock LLM) and `shop.py` don't need changing. In `tools.py`, leave `stock_sdk_lookup` alone: it's a third-party SDK.
